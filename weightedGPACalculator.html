How to Calculate Your Weighted GPA

Now that you know how to use this calculator, you might want to know how to do these calculations by yourself. Here's how to calculate your own GPA:

  • 1

    Convert Your Letter Grades to GPA Scale

    Use the chart below to convert each of you letter or number grades to weighted GPA scale. This program uses the 5.0 scale.

    e.g.  84 = 3.0
    e.g.  98 = 4.0
    e.g.  89 = 3.7

    • Letter Grade Percent Grade Regular/CP Honors AB/IP/College
    A+ 97-100 4.0 4.5 5.0
    A 93-96 4.0 4.5 5.0
    A- 90-92 3.7 4.2 4.7
    B+ 87-89 3.3 3.8 4.3
    B 83-86 3.0 3.5 4.0
    B- 80-82 2.7 3.2 3.7
    C+ 77-79 2.3 2.8 3.3
    C 73-76 2.0 2.5 3.0
    C- 70-72 1.7 2.2 2.7
    D+ 67-69 1.3 1.8 2.3
    D 65-66 1.0 1.5 2.0
    F <65 0.0 0.5 1.0
  • 2

    Add Together Converted Grades

    Take each course grade after being converted, and multiply it by that course's credits. Then add each of these results together.

    e.g.  (3.0 x 1) + (4.0 x 0.5) + (3.7 x 2) = 12.4

  • 3

    Find Total Amount of Credits

    Add together each cours's credits until you get the total amount of credits.

    e.g.  1 + 0.5 + 2 = 3.5

  • 4

    Calculate Your GPA

    Take the results from Step 2, and divide that number by the result from Step 3.

    e.g.  12.4 / 3.5 = 3.54

  • 5

    You're All Done!

    You're all done. Now you know how to calculate your own GPA
