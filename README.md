# grade-math.com
This is my first ever full HTML/CSS and JavaScript project. I started working on the first version the same day as I started my Web Development journey, and it's taken me about a month to get it to this state. I know it isn't perfect but it is full vanilla JavaScript and CSS, so overall I'm quite happy with what I've done here. Anyways I hope you enjoy this little grade calculator I've made here. It is a website that can be used to calculate many different things involved with grades. The list of calculators available is as follows: Grade Calculator(Average Grade), Final Grade Calculator(Final Grade Needed), Fast Grader(Test Grades), GPA Calculator(4.0), Weighted GPA Calculator(5.0), and Target GPA Calculator.
